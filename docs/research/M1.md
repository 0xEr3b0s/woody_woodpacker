### K1.1 Explain the role of the Elf64_Ehdr

This structure define the format of the ELF executable binary file.
It has one header file followed by program header table or Sections header table.
It's always at the beginning of the file.
Program header table can be found in the Ehdr.

### K1.2 Explain the role of Elf64_Phdr

Array of structures describing segment or other information the system needs to prepare the program for execution.
Program header are only meaningful for executable.

### K1.3 Explain how a PT_LOAD segment maps file bytes to memory.

PT_LOAD stand for "protected memory".
PT_LOAD is a flag holded by p_type ( Elf64_Phdr ), and it specifies a loadable segment.
p_filesz and p_memsz describe the PT_LOAD segment.
